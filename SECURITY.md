# Security Policy

At Voxora we look forward to working with security researchers across the world to keep Voxora and our users safe. If you have found an issue in any of our services, please reach out to us.

## Supported Versions
We always recommend using the latest versions of services to ensure you get all security updates

## Reporting a Vulnerability

If you believe you have found a security vulnerability within Voxora, please let us know right away. We'll try and fix the problem as soon as possible.

**Do not report vulnerabilities using public GitHub issues**. For issues in the original upstream project, use its [private advisory channel](https://github.com/dograh-hq/dograh/security/advisories/new). A separate private reporting channel for this Voxora fork has not yet been configured; contact the operator of your deployment for fork-specific issues.

Include the affected version, reproduction steps, and impact in your private report.

## Thanks

Thank you for keeping Voxora and our users safe. 🙇
